# Big Ambitions Monitor

Мониторинг бизнесов Big Ambitions в браузере: показатели бизнесов, проблемы,
остатки на складах и статистика прибыли. Панель — та же по духу, что и для Satisfactory.

Два способа получения данных из игры (панель `dashboard.html` у них общая):

| | **Мод в игре** (`mod/`) | **Внешний ридер сейвов** (`reader/`) |
|---|---|---|
| Данные | в реальном времени | при каждом сохранении/автосейве |
| Требует Steam | да (система модов игры завязана на инициализацию Steam) | нет |
| Требует запущенную игру | да | нет (читает файлы сейвов) |
| Как ставится | копия DLL в папку модов, включить в меню модов | запустить .exe |

Если игра запускается **через Steam** (пусть и в офлайн-режиме) — работает мод, данные live.
Если Steam не инициализируется (например, копия вне Steam) — система модов игры не
стартует; тогда используйте **внешний ридер**.

---

## Вариант A. Внешний ридер сейвов (без Steam)

Ридер следит за папкой сохранений, при каждом сохранении/автосейве десериализует самый
свежий `.hsg` и отдаёт снапшот + панель на `http://localhost:8113/`.

Запуск (нужен [.NET SDK 8+](https://dotnet.microsoft.com/download)):

```
Запустить-панель.bat
```

Скрипт соберёт ридер (при первом запуске) и откроет панель в браузере. Параметры при
необходимости:

```
reader\bin\Release\net8.0-windows\BigAmbitionsReader.exe ^
  --game  "D:\Big.Ambitions.v1.0\Big Ambitions\Big Ambitions_Data\Managed" ^
  --saves "%USERPROFILE%\AppData\LocalLow\Hovgaard Games\Big Ambitions\SaveGames"
```

По умолчанию папки берутся из стандартных путей (игра — `D:\Big.Ambitions.v1.0\...`,
сейвы — `AppData\LocalLow\Hovgaard Games\Big Ambitions\SaveGames`).

### Как это устроено

Файл сейва `.hsg` — это GZip поверх бинарного формата OdinSerializer с типами игры.
Ридер повторяет пайплайн десериализации самой игры
(`SaveGameSerializationHelper.DeserializeBinaryData`), ссылаясь на игровые DLL из вашей
копии. Игровые сборки собраны под Unity/Mono, поэтому в обычном .NET нужны два рантайм-обхода
(файл `reader/RuntimeShims.cs`, применяются только к процессу ридера, игру не трогают):

1. `UnityEngine.Debug.*` вне Unity падает на нативном вызове — глушим все перегрузки `Log*`
   (иначе статический конструктор `OdinSerializer.ArchitectureInfo`, который зовёт `Debug.Log`,
   «отравляет» весь тип).
2. OdinSerializer в emit-режиме вызывает устаревший `AssemblyBuilder.DefineDynamicModule(string, bool)`,
   которого нет в .NET Core — форсим `EmitUtilities.CanEmit=false`, и Odin переходит на
   рефлексивные форматтеры (через Harmony).

Ридер запускается на `net8.0`, потому что игровой код использует методы BCL
(`string.Contains(string, StringComparison)`), которых нет в .NET Framework 4.8.

## Вариант B. Мод в игре (при запуске через Steam)

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
```

Скрипт собирает DLL мода (нужен .NET SDK) и копирует её в
`%USERPROFILE%\AppData\LocalLow\Hovgaard Games\Big Ambitions\ModsLocal\BigAmbitionsMonitor`.

Дальше: запустить игру **через Steam** → включить мод **BigAmbitionsMonitor** в меню модов →
загрузить сейв → открыть <http://localhost:8113/>.

Мод раз в 3 секунды в главном потоке Unity снимает снапшот `SaveGameManager.Current` и
отдаёт его встроенным HTTP-сервером (та же панель, тот же порт).

> Локальный мод для игры — это папка в `ModsLocal` ровно с одной DLL, у которой есть
> атрибут `[assembly: RegisterModClass]`. Манифест нужен только для публикации в Steam Workshop.

## Структура

```
BigAmbitions/
  dashboard.html          общая веб-панель (обе схемы отдают её на :8113)
  shared/
    SnapshotCollector.cs  сбор снапшота из GameInstance (бизнесы, проблемы, склад, финансы)
    MonitorHttpServer.cs  HTTP-сервер (/api/snapshot + dashboard.html)
  reader/                 внешний ридер сейвов (net8.0)
    Program.cs            слежение за папкой сейвов, опрос, отдача
    SaveDeserializer.cs   распаковка + Odin-десериализация .hsg -> GameInstance
    RuntimeShims.cs       рантайм-обходы Unity/Odin под .NET
  mod/                    мод для игры (net48)
    MonitorMod.cs         точка входа [ModEntryOnCityLoad]
  install.ps1             сборка и установка мода в ModsLocal
  Запустить-панель.bat    сборка и запуск ридера
```

## Что показывает панель

- **Обзор** — наличные, капитал, число бизнесов, проблем, прибыль за день, график прибыли.
- **Бизнесы** — карточки: средний доход, покупатели и выручка за день, сотрудники,
  удовлетворённость (обслуживание/цены/чистота/помещение), мини-график дневной прибыли.
- **Проблемы** — выводятся из состояния: пустые/заканчивающиеся полки, недовольные и
  неназначенные сотрудники, закрытый бизнес, грязь, неоплаченные налоги.
- **Склад** — остатки по каждому зданию (полки, стеллажи, паллеты, коробки), фильтр по товару.
- **Финансы** — P&L за день по бизнесам (продажи, закупки, зарплаты, аренда, маркетинг,
  кражи, прибыль) и история недельного дохода.

## Ограничения

- Ридер: данные обновляются при сохранении игры, а не мгновенно; список проблем выводится
  из сохранённых полей (в файле сейва live-список задач игры не хранится).
- Мод: требует запуск игры через Steam.
- API игры неофициальный — после обновлений Big Ambitions мод/ридер может потребовать пересборки.
- Сервер слушает только localhost.
