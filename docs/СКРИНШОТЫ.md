# Скриншоты для README

Сделайте три скриншота панели (F12 не нужен, просто снимок окна) и сохраните в эту папку
с такими именами — README уже ссылается на них:

- `production.png` — вкладка «Производство» (карточки + советы + таблица)
- `power.png` — вкладка «⚡ Электричество» (сети, накопители, генераторы; можно с открытым круговым рубильником)
- `calculator.png` — вкладка «🧮 Калькулятор» с посчитанным рецептом

После добавления файлов этот файл можно удалить.
